## Crypto Messages
**Description:**
A cybersecurity research team has discovered that fictional threat actors are exchanging hidden messages inside otherwise ordinary HTML files. Instead of putting the message in visible webpage content, they place encoded text inside HTML <meta> elements and custom data-* attributes.
the purpose of this code is to build a safe simulator that creates these files.

**Key Concepts:** 
- Understanding how to utilize the 4 main Python data structures
- Applying file read/write concepts
- *New* exploring the Python "base64" library functionality

**Language:**
Python
